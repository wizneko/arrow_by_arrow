# Arrow Escape（箭路突围）

## 项目名称

Arrow Escape（箭路突围）

## 游戏简介

这是一个基于方向判断和消除顺序的解谜小游戏。棋盘中会随机分布不同方向的箭头，玩家需要判断每支箭头前方是否有其他箭头阻挡，按照合适的顺序点击它们，使所有箭头离开棋盘。游戏的核心是观察箭头方向、寻找当前可以移出的箭头，并逐步打开后续路线。

游戏共有 5 个关卡。第一关用于熟悉基本规则，从第二关开始，棋盘会逐渐扩大，箭头数量增加，箭头位置和方向也会打乱，关卡中会出现更多交叉阻挡关系。每关都有独立计时器，通关后会根据关卡难度、用时和误点次数计算评分。

主界面提供继续游戏和选择关卡功能。游戏过程中可以手动保存进度，关闭窗口时也会自动保存。计时器使用独立的单调时钟计算，不会因为箭头飞行动画或阻挡反馈而暂停。

项目整体采用暖色马卡龙风格，使用中文界面。箭头被阻挡时会显示路径、碰撞位置和抖动反馈；箭头成功移出棋盘时会播放飞出动画，并配有飞出和碰撞音效。通关和失败页面会播放对应的 GIF 动画，并配有相应提示音。游戏界面右侧放置了可点击的 AI 角色：初始状态会显示提示语，点击角色后会逐步执行当前可行的箭头，完成后显示成功动画，再进入结算页面。

最大化窗口或按 `F11` 进入全屏后，主界面、关卡选择、游戏棋盘和结算页面会按屏幕可用空间等比例放大并保持居中；退出全屏后恢复原来的窗口布局。

本项目的主要开发思路是：先用行列扫描判断箭头路径上的阻挡，再通过关卡生成器构造可通关的箭头布局。后续关卡在随机打散位置和方向的同时，增加阻挡链，并限制同一直线相邻位置出现连续同向箭头，使棋盘不会呈现整齐的重复图案。每次调整关卡后，都通过自动测试检查方向判断、阻挡逻辑、关卡可解性和评分功能。

## 开发环境

- 操作系统：Windows 11
- 开发语言：Python 3.13
- 图形界面：Tkinter
- GIF 处理：Pillow
- 可执行文件打包：PyInstaller
- 开发工具：Visual Studio Code

## 安装和运行方法

### 直接运行 exe

不需要安装 Python。进入 `dist` 文件夹，双击：

```text
ArrowEscape.exe
```

即可启动游戏。程序已经将 Pillow 和 GIF 资源打包进 exe，运行时不需要额外复制资源文件。

### 运行源代码

如果需要查看或修改源代码，请先安装 Python 3.10 或更高版本，然后在项目根目录执行：

```bash
python -m pip install Pillow
python main.py
```

### 重新打包 exe

安装 PyInstaller 后，在项目根目录执行：

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --name ArrowEscape --add-data "assets;assets" main.py
```

打包完成后，新的程序会生成在 `dist/ArrowEscape.exe`。

## 游戏操作说明

1. 点击棋盘中的箭头。
2. 如果箭头前方没有其他箭头，它会沿自身方向飞出棋盘。
3. 如果前方存在箭头，当前箭头会被阻挡，并消耗一次机会。
4. 每关最多允许两次失误，清空棋盘后进入下一关，最后一关完成后显示总评分。
5. 两次失误次数耗尽后本局失败，可以重新挑战。

快捷键：

- `R`：重新开始当前关卡
- `H`：显示一个可以直接移出的箭头提示
- 游戏界面右侧的“AI 一键逐步求解”：逐步执行当前可行的箭头，可以随时暂停
- `F11`：切换全屏
- `Esc`：退出全屏或返回主界面

主界面中的“选择关卡”可以进入已经解锁的关卡；游戏界面中的“保存”按钮可以手动保存当前进度。返回主界面或关闭窗口时，程序也会自动保存当前关卡。
